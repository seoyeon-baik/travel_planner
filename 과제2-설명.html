AI와 함께 만들기:
Vibe Coding 웹 애플리케이션

AI Coding Agent와 협업해 자신의 아이디어를 실제로 작동하는 웹 앱으로 구현하고 웹에 배포하는 과제입니다.

1. 과제 목적

이번 과제에서는 AI Coding Agent(예: Codex)를 활용하여 자신만의 웹 애플리케이션을 개발하고, 실제 웹에 배포해 봅니다.

이 과제의 목적은 복잡한 프로그래밍 코드를 직접 작성하는 것이 아니라, AI와 협업하여 자신의 아이디어를 실제로 작동하는 웹 애플리케이션으로 구현하는 경험을 하는 것입니다.

특히 웹 애플리케이션의 기본 구조와 작동 원리를 이해하고, AI가 생성한 결과를 직접 실행하고 검토하며, 발생한 문제를 해결하는 과정을 중요하게 평가합니다.

2. 과제 수행 내용

① 웹 애플리케이션 주제 선정

일상생활이나 사회에서 발견할 수 있는 문제 또는 필요를 하나 선정하고, 이를 해결하거나 지원할 수 있는 간단한 웹 애플리케이션을 기획합니다.

주제 예시

  • 개인 지출 기록 및 관리 앱
  • 학교 주변 시설 정보 공유 앱
  • 분실물 등록 및 검색 앱
  • 운동 기록 및 관리 앱
  • 책·영화 기록 및 평가 앱
  • 지역 맛집 정보 공유 앱
  • 학습 일정 관리 앱
  • 사회문제 관련 기사 북마크 앱
  • 환경 실천 기록 앱
위의 예시 이외에도 자유롭게 주제를 선정할 수 있습니다. 주제의 사회적 중요성이나 규모보다는 웹 애플리케이션으로 구현하기 적절하고 실제로 작동하는 기능을 갖추었는지가 더 중요합니다.

② 주요 기능 및 요구사항 정의

개발을 시작하기 전에 앱의 목적과 주요 기능을 구체적으로 정의합니다. 예를 들어, 지역 문제 공유 앱은 다음과 같은 기능을 가질 수 있습니다.

  • 사용자가 지역의 문제를 등록할 수 있다.
  • 등록된 문제의 목록과 내용을 확인할 수 있다.
  • 자신이 등록한 게시물을 수정하거나 삭제할 수 있다.

처음부터 복잡한 기능을 구현할 필요는 없습니다. 앱의 목적을 달성하는 데 필요한 핵심 기능부터 개발합니다.

③ AI Coding Agent를 활용한 개발

Codex 등의 AI Coding Agent를 활용해 개발합니다. AI에게 단순히 “웹 앱을 만들어 줘”라고 요청하기보다 다음 순서로 진행하시기 바랍니다.

  1. 문제 정의: 어떤 문제를 해결하거나 어떤 필요를 충족할 것인지 결정합니다.
  2. 요구사항 작성: 앱에서 구현해야 할 주요 기능을 정리합니다.
  3. 개발 계획: AI와 함께 앱의 구조와 개발 방법을 결정합니다.
  4. 구현: AI Coding Agent를 활용해 실제 코드를 생성하고 앱을 개발합니다.
  5. 실행 및 테스트: 앱을 직접 실행해 의도한 대로 작동하는지 확인합니다.
  6. 오류 수정 및 개선: 발생한 문제를 AI와 함께 해결하고 기능을 개선합니다.

④ 데이터 저장 및 관리 기능 구현

앱에는 데이터를 입력하고 저장하거나 관리할 수 있는 기능이 포함되어야 합니다. 목적에 맞게 데이터 입력, 저장, 조회, 수정, 삭제 등의 기능 중 필요한 기능을 구현합니다. 필요한 경우 Neon 등의 데이터베이스 서비스를 활용할 수 있습니다.

⑤ 웹 애플리케이션 배포

Vercel 등의 서비스를 이용해 앱을 실제 웹에 공개합니다. 배포한 URL로 누구나 접속해 앱의 주요 기능을 사용할 수 있어야 합니다.

⑥ AI 활용 및 문제 해결 과정 기록

이번 과제에서는 완성된 웹 앱뿐 아니라 AI와 협업하여 개발한 과정도 중요합니다.

개발 과정에서 발생한 실질적인 오류·문제점과 이를 해결하거나 개선하기 위해 AI Coding Agent와 상호작용한 사례는 모두 기록하시기 바랍니다.

각 사례에는 다음 내용을 포함합니다.

  • 문제 상황: 어떤 오류나 문제점, 개선할 부분이 발견되었는가?
  • AI 활용: 문제 해결을 위해 AI에게 어떤 요청이나 수정 지시를 했는가?
  • 해결 과정: AI가 어떤 해결 방법을 제안했고, 이를 어떻게 적용했는가?
  • 최종 결과: 문제가 해결되었는가? 해결되지 않았다면 어떤 한계가 남았는가?

프로그래밍 오류뿐 아니라, 기능 오작동, 의도와 다른 화면 구성, 추가 지시를 통한 기능 개선 등의 사례도 포함할 수 있습니다. 다만 단순한 질문이나 사소한 문구 수정처럼 실질적인 문제 해결·기능 개선과 관계없는 대화까지 모두 기록할 필요는 없습니다.

3. 제출물

다음 항목을 포함하여 개발 보고서를 작성해 제출합니다.

  1. 웹 애플리케이션 URL: 실제 배포된 웹 앱에 접속할 수 있는 주소
  2. GitHub Repository URL: 개발한 앱의 소스코드가 저장된 GitHub 저장소 주소
  3. 앱 소개: 개발 목적과 주요 기능에 대한 간단한 설명
  4. 주요 화면 캡처: 앱의 주요 화면과 기능을 확인할 수 있는 이미지
  5. AI 활용 및 문제 해결 과정: 개발 과정에서 발생한 실질적인 문제, 오류, 기능 개선 사항과 AI를 이용한 해결 과정을 모두 정리한 기록

웹 앱 URL과 GitHub 저장소 URL도 보고서에 포함하시기 바랍니다.

보고서 분량은 고정하지 않습니다. 실제로 경험한 문제 해결 및 개선 사례를 충분히 담되, 각 사례는 명료하게 정리하시기 바랍니다.

6. 과제 수행 시 유의사항

이번 과제에서 중요한 것은 얼마나 복잡한 웹 애플리케이션을 만들었는지가 아니라, 자신의 아이디어를 AI와 협업하여 실제로 작동하는 앱으로 구현하고, 그 과정에서 발생하는 문제를 스스로 파악하고 해결하는 경험입니다.

처음부터 완벽한 결과물을 만들려고 하기보다 간단한 기능부터 구현하고, 직접 실행하고 테스트하면서 점진적으로 개선하시기 바랍니다.

AI가 생성한 코드를 모두 직접 작성하거나 완벽하게 이해할 필요는 없지만, 자신이 만든 앱의 주요 기능과 작동 방식은 설명할 수 있어야 합니다.
